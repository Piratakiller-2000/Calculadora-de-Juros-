# 📈 Calculadora de Juros Compostos

Aplicação desktop nativa desenvolvida com Python e `pywebview`, trazendo uma interface em Fluent Design moderna com motor financeiro multimoeda e suporte a juros compostos.

## 🚀 Funcionalidades

- **Cálculo de Juros Compostos:** Entradas de aporte inicial, aporte mensal, período (meses/anos) e taxa de juros.
- **Suporte Multimoeda:** Formatação em tempo real para Real (R$), Dólar ($), Euro (€) e Libra (£).
- **Entrada Inteligente:** Teclado virtual e suporte a teclado físico com conversão de separadores decimais e milhares.
- **Tabela Evolutiva:** Aba para acompanhamento do rendimento mês a mês ou ano a ano.

## 💻 Tecnologias

- **Backend:** Python 3, `pywebview`, Pillow
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Compilação:** PyInstaller

## 🔧 Como Executar em Desenvolvimento

```bash

git clone [https://github.com/SEU_USUARIO/calculadora-juros-compostos.git](https://github.com/SEU_USUARIO/calculadora-juros-compostos.git)

pip install pywebview pillow
